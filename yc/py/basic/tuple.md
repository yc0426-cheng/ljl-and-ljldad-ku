可以存储不同类型的元素
元组一旦定义，就不允许修改，元素有序，可重复

定义 ：
    元组名称 = () <p>
    元组名称 = tuple()

方法：

- count()：统计某元素在元组中出现的次数
- index()：查找某个元素在元组中的索引位置（第一次出现的位置）

t = (10)  == t =10 这是赋值<p>
t = (10,) == 这是元组


- 组包（Packing）：将多个值合并到一个容器（元组、列表）中。
- 解包（Unpacking）：将容器（元组、列表）解包成独立的元素，分别赋值给多个变量。

```python
# 定义元组，组包
t1 = (5, 7, 9, 1)
# 定义元组，组包
t2 = 5, 7, 9, 1

# 基础解包
a, b, c, d = t1

# (*)扩展解包
x, *y, z = t2  # x为5，y为[7, 9]，z为1
s, *o = t2     # s为5，o为[7, 9, 1]
*o, e = t2     # o为[5, 7, 9]，e为1

这个o和y生成的是列表

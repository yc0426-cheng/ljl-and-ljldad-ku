# AI 成长型学习仓库

> 一个能够持续吸收、理解并应用新知识的智能系统。

本项目搭建了一套基于 **RAG（检索增强生成）** 技术的知识库系统，核心目标是解决大模型在特定领域知识更新滞后及"幻觉"（编造答案）问题，实现基于私有文档的精准问答与知识检索。

简单说：把你的文档放进知识库，AI 就能"基于你的文档"回答问题，并告诉你答案来自哪里——而不是凭空瞎编。

---

## 功能特性

- **本地知识库**：把 `app/data/` 目录下的 Markdown 文档自动切分、向量化并存入向量数据库。
- **增量更新**：文档新增、修改、删除后自动检测，只更新变化的部分，无需全量重建。
- **精准问答**：基于检索到的资料片段回答，答案标注来源文件，方便溯源。
- **防幻觉**：通过提示词约束，资料里没有的信息 AI 会明确回答"资料中没有找到"，而不是编造。
- **命令行交互**：简单易用，输入问题即得答案。

## 技术栈

| 组件 | 选型 | 通俗说明 |
|------|------|----------|
| RAG 框架 | llama-index | 组装"检索 + 生成"流程的脚手架 |
| 大语言模型 | 通义千问 `qwen-plus`（DashScope） | AI 的"大脑"，负责组织语言回答 |
| 嵌入模型 | `BAAI/bge-small-zh-v1.5`（本地） | 把文字变成"坐标"，让电脑能判断文字相关性 |
| 向量数据库 | ChromaDB（本地） | 存放"坐标点"的仓库，检索时找最相近的点 |
| 配置管理 | python-dotenv | 从 `.env` 文件读取密钥，密钥不写进代码 |

## 快速开始

### 1. 环境准备

需要 Python 3.10 及以上版本（本项目在 Python 3.14 下测试通过）。

### 2. 安装依赖

```bash
cd python_service

# 方式一：使用已有虚拟环境（推荐）
.venv\Scripts\activate          # Windows
# 或 source .venv/bin/activate   # Mac / Linux

# 方式二：或直接安装
pip install -r requirements.txt
```

### 3. 配置 API 密钥

在 `python_service/` 目录下创建 `.env` 文件（与 `app/` 同级），内容如下：

```
DASHSCOPE_API_KEY=你的通义千问API密钥
```

密钥在 [阿里云百炼平台](https://bailian.console.aliyun.com/) 申请。`.env` 已被 `.gitignore` 保护，不会随代码上传。

### 4. 准备知识文档

把你希望 AI 学习的 Markdown 文档放入 `app/data/` 目录。

### 5. 启动使用

```bash
cd python_service\app
python main.py
```

程序首次运行会自动构建索引，之后即可开始问答。

## 使用说明

启动后是一个交互式问答界面：

| 输入 | 作用 |
|------|------|
| 你的问题（如：`宿舍档案里舍长是谁？`） | AI 检索知识库并回答，附带来源 |
| `reload` | 重新扫描 `data/` 目录，更新索引（新增/修改/删除文档后使用） |
| `exit` 或 `quit` | 退出程序 |

### 添加新知识

1. 将新的 Markdown 文件放入 `app/data/`
2. 在程序里输入 `reload`（或重启程序）
3. 程序会自动检测新文件，只索引新增部分

## 配置说明

如需调整，可在 `app/main.py` 顶部修改以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TOP_K` | 5 | 每次检索的资料片段数，越大信息越全但更耗 token |
| `CHUNK_SIZE` | 512 | 文档切块大小（字符数） |
| `CHUNK_OVERLAP` | 50 | 相邻块之间的重叠字符数，避免切块丢失上下文 |
| `EMBED_MODEL_NAME` | `BAAI/bge-small-zh-v1.5` | 本地嵌入模型 |
| `LLM_MODEL_NAME` | `qwen-plus` | 通义千问模型，可换 `qwen-max`（更强但更贵） |

> 修改 `EMBED_MODEL_NAME` 后需删除 `app/chroma_db/` 目录重新构建索引。

## 常见问题

**Q：提示"未找到 DASHSCOPE_API_KEY"？**
检查 `python_service/.env` 文件是否存在、密钥是否正确。

**Q：首次运行很慢？**
首次运行需要下载嵌入模型并构建索引，属正常现象。之后运行会快很多。

**Q：模型下载很慢或失败？**
若网络不畅，可配置代理或使用 HuggingFace 国内镜像。

**Q：每次启动都很慢（卡在模型加载）？**
嵌入模型已下载到本地后，程序默认启用"离线模式"（`main.py` 中的 `HF_HUB_OFFLINE=1`），跳过联网检查，启动会快很多。若需要联网下载/更新模型，把该值改为 `"0"` 或删除这两行即可。

**Q：索引没更新，回答的还是旧内容？**
在程序里输入 `reload` 手动刷新索引，或重启程序。

**Q：想清空知识库重来？**
删除 `app/chroma_db/` 目录和 `app/chroma_db/index_meta.json`，重新运行程序即可。
